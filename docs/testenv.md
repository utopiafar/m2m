# 测试环境基线

> G3 性能验收要求"固定设备基线"。本文件已按 2026-09-30 的**实测侦察**填写。
> 未记录的项视为未验证；任何变更需追加到 §7 变更记录。

## 0. 拓扑结论（重要）

**一期全部三端（Host / Relay / Viewer）与测试对象运行在同一台机器上**（决策 I2）。

由此产生的两条硬约束，写进所有性能报告的前提：

1. **编解码争用同一硬件媒体引擎**：单机测得端到端延迟**偏悲观**，不能代表双机部署的真实值。
2. **本机为无风扇机型**：持续编码+解码负载会触发热降频，长时间测试的数据会随热状态漂移。

因此：**单机数据用于功能正确性与相对比较；绝对性能结论必须由 L6（双机/真实网络）给出。**

| 项 | 值 | 对项目的影响 |
|---|---|---|

## 7. 自动化能力（实测）

| 能力 | 状态 | 说明 |
|---|---|---|
| XCUITest | **可用** | Xcode 27 已装，可编译并运行 UI 测试 target |
| **computer-use：应用枚举** | **可用** | 实测 `listApps` / `getState` 返回 9 个应用 |
| **computer-use：AX 树读取** | **不可用（待授权）** | 实测 `getElements` / `getAXState` 对系统设置、终端均失败，错误指向 TCC 授权：*"If Accessibility was just granted to the Helper, restart the Helper so its process re-reads the TCC grant."* |
| **computer-use：截图** | **不可用（待授权）** | 同上；截图需额外授予屏幕录制 |
| TCC 授权状态查询 | 不可用 | 无完全磁盘访问权限，`TCC.db` 不可读；授权状态只能从系统设置界面确认 |

**解锁 computer-use 的步骤**（需要你人工操作一次）：

1. 系统设置 → 隐私与安全性 → **辅助功能** → 勾选 `ZCode Helper`
2. 系统设置 → 隐私与安全性 → **屏幕录制** → 勾选 `ZCode Helper`（用于截图验收）
3. 重启 ZCode Helper（退出并重开 ZCode，或让 Helper 进程重启），使其重新读取 TCC 授权
4. 复测：`listApps` + `elements` + `getScreenshot` 三项

授权前，L4/L5 测试层的 computer-use 通道视为**不可用**，视觉验收走人工。
