## 一、阻塞项：只有你知道的环境事实

这些不是选择题，我没法替你推断，缺了它们 M0 无法执行（尤其 G3 性能基线要求固定设备与网络条件）。

| 编号 | 需要你提供 | 为什么阻塞 | 影响 |
|---|---|---|---|
| **F1** | 两台 Mac 的**型号、内存、macOS 版本、显示器与缩放模式** | G3 要求"固定测试设备基线"；T4/T5 的编码选型要基于实测 | 决定 H.264/HEVC 档位、能否统一系统版本（P7）、虚拟显示器方案是否必需 |
| **F2** | **远端 Mac 的现状**：是否已购买/已就位？在哪里（哪个国家/城市）？家庭还是托管？ | 决定 M0 能否用真实跨境线路测量 | 影响 G3 的可信度与里程碑排期 |
| **F3** | **远端网络条件**：上行带宽实测值、是否可保持常开、有无月流量上限 | 见 `05` §10 的流量测算；上行决定可用码率与画质 | 决定 P10 的降级阈值与是否需要商业宽带 |
| **F4** | **远端 Mac 的物理访问条件**：能否重启、能否授权屏幕录制/辅助功能、是否有 FileVault、是否有物理显示器或 HDMI dummy | Host 需要屏幕录制与辅助功能权限；无显示器时需要虚拟显示器方案 | 决定 M0 是否要先准备 BetterDisplay Pro（$21.99）或虚拟显示驱动 |
| **F5** | **远端 Mac 上 Claude 的安装与登录状态**：是否已安装？账号是否可登录？登录过程是否需要浏览器跳转（P5 场景） | 目标应用不可用就无法做兼容性验证 | 决定 M0 是否需要先做 P5 的临时授权窗口 |

> **F4 特别提醒**：调研明确区分了"机器旁边没人"和"系统没有登录用户"。Host 必须是**用户会话内的 Agent**（系统级 daemon 没有 WindowServer 访问能力）。因此远端 Mac 必须**保持已登录状态且不休眠**——这是运行前提，不是可以后面再解的问题。

## 二、不阻塞编码，但影响路线的意图确认

这些我已按推荐值锁定，**如果你没有不同意的理由，我就不问了**。列出是因为它们会在特定时点产生实质差别。

| 编号 | 需要你确认 | 锁定值（默认） | 若你的实际情况不同 |
|---|---|---|---|
| **I1** | 这个项目最终是**只自用**，还是可能开源/商业化？ | 按"有商业化可能"处理：只选择许可证边界清楚的依赖（MIT / Apache-2.0），**不整仓 fork AGPL 项目** | 若确定永久自用且不分发，可以复用 RustDesk / Transom / Hopp 的 AGPL 代码，能省一部分实现工作 |
| **I2** | 是否会需要**多台远端 Mac** 或**多人使用**？ | 一期按单台、单控制者 | 若需要多台，Relay 的设备管理模型要提前设计（一期不做，但接口会预留） |
| **I3** | 是否真的需要**系统音频/麦克风**（例如你想听远端 Mac 的声音）？ | 一期不做音频（P8） | 若需要，音频通道要在协议里预留位（现在只占位不实现，改比后期加便宜） |
| **I4** | 远端 Mac 是否**只跑 Claude**，还是会同时跑其他需要远控的应用？ | 按"通用内核 + 有限认证应用"，但 M0/M1 的资源优先给 Claude | 若有其他刚需应用，认证清单要调整，测试面会扩大 |

## 三、会在特定时点找你的决策（现在不需要回答）

这些**现在不应该决定**，因为答案取决于真机数据。我列出来是为了让你知道会在什么时候被问到。

| 时点 | 会被问到什么 | 为什么不能现在定 |
|---|---|---|
| **G1 出结果后** | 如果 Claude 只能提供"最后点击位置"级别的插入点信息：**(a) 追加预算开发 Claude 专用适配器，还是 (b) 接受降级标识？** | 这是本项目最可能出现的岔路。P2 已锁定"认证应用必须达到光标附近本地组合"，所以按规则 Claude 不能直接进认证列表；是补适配器还是接受降级，是价值判断，必须看实际难度 |
| **G2 出结果后** | 若弹窗/多窗口必须改用图集方案，是否接受媒体链路重做 | 取决于实测的多窗口编码压力 |
| **G3 出结果后** | 若实际码率显著高于测算，是否升级宽带/中继方案 | 取决于实测数字 |
| **P9 定案时（M3 前）** | 分发方式与依赖清单最终确认 | 影响能否复用 AGPL 代码；M3 才需要 |
| **M0 完成后** | 是否按原预算进入 M1（50–100 h），还是按实测重新估 | 调研明确要求：若发现 Claude 特殊窗口或输入行为不兼容，应根据实测重新估 |
