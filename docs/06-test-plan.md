# 06 测试计划

## 1. 测试原则

| 原则 | 说明 |
|---|---|
| **不许用"视频传通了"当完成标志** | 完成定义见 `01-overview.md` §6 |
| **不许用程序化注入替代真实输入法测试** | AppKit 组合文本机制与 `AXValue`/Playwright setValue 不是同一条路径 |
| **不许只在局域网验收** | 必须注入 80 / 160 ms RTT 与丢包 |
| **不许用 Claude 做唯一测试对象** | 会把"应用自身行为 / 远控协议问题 / 输入法问题"混在一起，失败难以归因，Agent 会反复猜 |
| **必须能区分归因** | 先用可控测试 App 验证通用链路，再用 Claude 验证兼容性 |

## 2. 测试对象

### 2.1 可控测试 App（必须自建，属于一期交付物）

| 测试 App | 类型 | 必须包含的可断言元素 |
|---|---|---|
| `TestApp-Native` | AppKit | 文本框（NSTextField）、多行文本视图、**有 min/max 尺寸约束的可缩放窗口**、菜单栏、模态对话框、Sheet、右键菜单、文件选择器、`contenteditable` 等价物（NSTextView）、可切换焦点的两个窗口 |
| `TestApp-Electron` | Electron | 同上 + 虚拟滚动列表 + `contenteditable` 聊天输入 + 独立的设置窗口 |

**控件状态必须可自动断言**（例如通过一个只读的本地 IPC/AX 接口报告当前文本内容、选区、窗口尺寸），否则 Agent 无法闭环。

**校验接口约束**：断言通道只能**读取**状态；它不得成为产品的一部分，也不得暴露到网络。

### 2.2 真实目标

| 对象 | 用途 |
|---|---|
| 官方 Claude Desktop（固定版本） | 兼容性验证；版本号记录在案 |
| 第二台 Mac 上的系统输入法 | 真实拼音输入 |

### 2.3 测试设备基线（G3 前置）

| 项 | 要求 |
|---|---|
| 两台 Mac | Apple Silicon；型号、内存、系统版本写入 `docs/testenv.md` |
| 系统版本 | 尽量统一（P7） |
| 显示器 | 记录分辨率与缩放模式 |
| 网络 | 局域网基线 + 可注入延迟/丢包的工具（如 `dnctl`/`pfctl` 或网络模拟器） |

## 3. 需求 → 测试映射

### 3.1 窗口（Window）

| 编号 | 用例 | 判据 |
|---|---|---|
| T-WIN-01 | 远端 Claude 主窗口在本地独立出现 | 本地出现 `NSWindow`；**不显示远端桌面**；可与本地 App 混排 |
| T-WIN-02 | 本地移动窗口 | 移动立即生效；远端窗口坐标**不**随之改变 |
| T-WIN-03 | 缩放并重新排版 | 松手后远端重新排版，文字恢复清晰（非长期放大旧画面） |
| T-WIN-04 | 最小尺寸约束 | 拖到小于应用最小值 → 本地接受约束，不抖动；给出 `constrained_by` 提示 |
| T-WIN-05 | 不可缩放窗口 | 该窗口不允许拖动缩放（或拖动后立即回弹并解释） |
| T-WIN-06 | 打开设置窗口 | 本地新建独立壳，父子/模态正确 |
| T-WIN-07 | 打开 Sheet / 模态对话框 | 模态约束正确：模态期间主窗口不接受输入 |
| T-WIN-08 | 右键菜单 | 出现在主窗口附近，**不被其他本地窗口遮挡** |
| T-WIN-09 | 文件选择器 | 以远端文件对话框形式正确呈现 |
| T-WIN-10 | 最小化 / 恢复 | 画面暂停而非持续发静止帧；恢复先发关键帧，无花屏 |
| T-WIN-11 | 关闭语义区分 | "关闭本地壳" ≠ "关闭远端应用" ≠ "断开会话"（三者行为分别验证） |
| T-WIN-12 | 远端窗口消失 | 本地壳被正确关闭；**不得留下接收输入的僵尸窗口** |
| T-WIN-13 | 未识别窗口类型 | 建壳并标注；**不得自动退化为共享整个远端桌面** |
| T-WIN-14 | 跨应用登录（浏览器跳转） | 按 P5：临时授权相应应用窗口；不自动暴露整桌面 |
| T-WIN-15 | 快速连续缩放 | `request_seq` 合并生效，无请求风暴，无抖动 |

### 3.2 输入（文本）

见 `04-text-input.md` §7 的 T-CN-01 … T-CN-16。**全部为 P0。**

### 3.3 输入（键鼠）

| 编号 | 用例 | 判据 |
|---|---|---|
| T-IN-01 | 鼠标点击远端按钮 | 远端正确响应；本地点击位置映射正确（含缩放后的映射） |
| T-IN-02 | 滚动 | 平滑；不发生"滚动惯性继续很久"的累积延迟 |
| T-IN-03 | Cmd+C / Cmd+V / Cmd+Z 等快捷键 | 送往远端应用且语义正确 |
| T-IN-04 | 修饰键跟踪 | 按下 Cmd 后断线 → 重连后不残留按下状态 |
| T-IN-05 | 鼠标移动合并 | 高频移动下带宽占用与延迟受控 |
| T-IN-06 | 快捷键与输入法冲突 | Cmd+Space（切换输入法）等**由本地处理**，不送往远端 |
| T-IN-07 | 焦点切换 | 本地切换窗口时，先让远端确认目标窗口有效并获得焦点，再发送输入 |
| T-IN-08 | 输入不得跨窗口 | 每条输入带窗口身份；窗口 A 的输入不得落到窗口 B |

### 3.4 媒体与性能（G3）

| 编号 | 用例 | 判据 |
|---|---|---|
| T-MED-01 | 局域网延迟基线 | 记录采集/编码/传输/解码/显示/排队各自耗时与端到端中位数 |
| T-MED-02 | 注入 80 ms RTT | 记录操作反馈；与基线对比，额外开销可解释 |
| T-MED-03 | 注入 160 ms RTT | 同上 |
| T-MED-04 | 丢包 1% / 3% / 5% | 无花屏长时间持续；恢复后画质正常 |
| T-MED-05 | 文字清晰度 | 常用字号在静态下清晰；不出现长期低分辨率拉伸 |
| T-MED-06 | 延迟稳定性 | 连续操作 10 分钟，延迟无单调累积 |
| T-MED-07 | 后台窗口降频 | 后台流带宽/CPU 显著低于前台 |
| T-MED-08 | H.264 vs HEVC 对比 | 同画质下比较码率与延迟，形成数据（不预设结论） |
| T-MED-09 | 文件上传不阻塞输入 | 上传 1 GB 文件期间，点击与输入保持正常响应 |
| T-MED-10 | 质量降级可见 | 弱网下用户能感知当前为降级模式 |

### 3.5 剪贴板与文件

| 编号 | 用例 | 判据 |
|---|---|---|
| T-CLIP-01 | 文本双向 | 本地复制 → 远端粘贴；远端复制 → 本地粘贴 |
| T-CLIP-02 | 图片双向 | 截图粘贴到远端；远端图片复制到本地 |
| T-CLIP-03 | 防回环 | 同一内容不被反复往返 |
| T-FILE-01 | 拖入上传 | 进度可见；远端临时目录出现文件；可在远端文件选择流程中使用 |
| T-FILE-02 | 上传中断 | 中断后可重试；无半截文件被使用 |
| T-FILE-03 | 临时文件清理 | 会话结束/超限后清理 |
| T-FILE-04 | 不冒充本地文件系统 | 远端文件对话框**不**直接列出本地磁盘（一期明确不支持，见 P4） |

### 3.6 会话与恢复（G4）

| 编号 | 用例 | 判据 |
|---|---|---|
| T-REC-01 | 网络中断 5 秒 | 画面冻结 + 状态提示；恢复后不重放输入 |
| T-REC-02 | 网络中断 60 秒 | 会话保留；远端应用未关闭；重连后窗口注册表一致 |
| T-REC-03 | 中断期间点击"发送" | **不自动重试**；重连后界面提示结果未确认；远端无重复消息 |
| T-REC-04 | 远端应用崩溃重启 | `app_launch_id` 变化；旧身份输入被拒绝；本地窗口重建 |
| T-REC-05 | 远端窗口切换中断线 | 重连后焦点重读；本地组合文本清空 |
| T-REC-06 | Host 进程重启 | 重建注册表，不重放旧输入；无修饰键卡住 |
| T-REC-07 | 权限被撤销 | 明确提示（屏幕录制 / 辅助功能分别提示），而非静默失败 |
| T-REC-08 | 撤销控制 | 即使在媒体链路异常时，撤销指令仍能生效 |
| T-REC-09 | 长时间运行 | 8 小时连续连接：无内存增长、无句柄泄漏、无延迟累积 |
| T-REC-10 | 多窗口重连一致性 | 重连后本地壳数量与远端窗口一一对应 |

### 3.7 安全

| 编号 | 用例 | 判据 |
|---|---|---|
| T-SEC-01 | 未配对设备连接 | 被拒绝 |
| T-SEC-02 | 配对码错误多次 | 限速 / 锁定 |
| T-SEC-03 | 传输内容检查 | 抓包确认媒体与数据端到端加密；中继不可读业务内容 |
| T-SEC-04 | 日志内容 | 诊断日志不含聊天正文 |
| T-SEC-05 | 调试接口 | 不监听公网；默认关闭 |
| T-SEC-06 | 权限撤销生效 | 本地撤销后远端立即停止接受控制 |

## 4. 弱网矩阵

| 维度 | 取值 |
|---|---|
| RTT | 局域网基线 / 80 ms / 160 ms / 250 ms |
| 丢包 | 0% / 1% / 3% / 5% |
| 抖动 | 0 / 20 ms / 50 ms |
| 带宽上限 | 不限 / 20 Mbps / 8 Mbps / 3 Mbps |
| 场景 | 静态阅读 / 滚动 / 连续输入法输入 / 上传文件 / 长时间挂机 |

**验收规则**：3 Mbps + 160 ms + 1% 丢包组合下，**窗口操作与候选词仍需本地即时响应**（这是分层架构的意义）；远端内容反馈可以变慢，但不得花屏、不得累积、不得误发送。

## 5. G1–G4 门槛的执行方式

| 门槛 | 测什么 | 产物 | 影响哪个决策 |
|---|---|---|---|
| **G1 文本输入闭环** | T-CN-01…16；重点 caret rect 是否可稳定获得、选词 Enter 是否误发送 | `docs/reports/G1-text.md` + 录屏 | 通用 AX 是否够用 / 是否必须 Claude 专用适配器；P2 能否达标 |
| **G2 窗口完整性** | T-WIN-01…15 | `docs/reports/G2-window.md` | 逐窗口流 vs 图集；弹窗处理方案 |
| **G3 性能基线** | T-MED-01…10 | `docs/reports/G3-perf.md` + 原始数据 | H.264/HEVC、WebRTC 构建是否达标；T4/T5 是否调整 |
| **G4 恢复与错误输入** | T-REC-01…10 | `docs/reports/G4-recovery.md` | 会话状态机能否进入日常使用 |

**门槛未过时的处理**：不得"先继续做，后面再补"。G1 未过 → Claude 不得进入认证列表（或必须开发专用适配器后再评）。

## 6. Agent 自动化边界

| 适合 Agent 自动做 | 必须人工/真机做 |
|---|---|
| `Protocol` / `WindowCore` / `TextBridge` 的单元测试（不启动 GUI） | 真实系统输入法的组合与候选窗交互 |
| 可控测试 App 的状态断言（读接口） | 视觉判断：候选窗位置是否"贴近插入点" |
| 弱网注入下的日志采集与指标聚合 | 输入法手感与"别扭感"的判断 |
| 回归运行、指标对比、报告生成 | 权限授予流程、跨机器首次配对 |
| 花屏/关键帧/重连的协议级测试 | 应用特定行为（Claude 的特殊窗口、剪贴板交互） |

**禁止 Agent 做的事**：见 `09-agent-rules.md`。

## 7. 回归策略

| 频率 | 内容 |
|---|---|
| 每次提交 | 单元测试（协议、状态机、几何映射） |
| 每日 | 局域网冒烟：窗口 + 中文输入 + 缩放 + 剪贴板 |
| 每周 | 弱网矩阵抽样 + 长时间运行抽样 |
| 版本升级 Claude 后 | **全量 T-CN + T-WIN**（应用更新是最可能的破坏源） |
| 系统升级后 | 权限、AX 行为、ScreenCaptureKit 行为复测 |
